# Bilim Premium: іске қосу / запуск

## Жергілікті іске қосу

Жоба түбірінде / из корня проекта:

```sh
python -m http.server 5500 --directory frontend
```

Открыть **http://localhost:5500**. Альтернатива: VS Code → `frontend/index.html` → **Open with Live Server**.
Двойной клик по HTML (`file://`) блокирует ES modules. Страница теперь показывает инструкцию, а не пустую форму.
Вложенный путь поддерживается для landing; существующие кабинеты используют `/assets/`, поэтому для полного приложения корнем сервера должен быть **frontend**.

## Firebase

В `frontend/assets/firebase-config.js` остаётся исходная конфигурация с `PASTE_...`. Вставьте **публичные параметры веб-приложения своего существующего Firebase-проекта** из Firebase Console → Project settings → Your apps. Не помещайте service-account keys в браузерный код.

В том же проекте включите Authentication → Email/Password, проверьте Authorized domains (localhost и домен развернутого сайта), наличие Firestore и опубликованные правила из существующего `firestore.rules`. Не открывайте публичную запись и не назначайте admin при регистрации. Начальная настройка пользователей/материалов описана в исходном README и `setup.html`.

Форма работает независимо от инициализации Firebase и WebGL; без Firebase показывает ошибку настройки. Реальные запросы по-прежнему выполняет исходный `backend.js`: маршруты, CSRF-контракт, сессии и проверка ролей сохранены. Регистрация teacher сохраняет `blocked: true`; перехода в кабинет до одобрения нет. Публичной регистрации admin нет.

После настройки вручную проверить: student signup/login/logout; teacher signup → pending → одобрение в admin → teacher login; admin login; неверный пароль; запрет доступа к чужим кабинетам. Нужны настоящие тестовые аккаунты в вашем проекте. Демокнопки только заполняют исходные данные; они не создают аккаунты.

## Docker

Отдельного шага компиляции нет: это статический frontend. Из корня:

```sh
docker compose build
docker compose up -d
```

Открыть **http://localhost:8084**. Порт 8084 должен быть свободен.

```sh
docker compose logs --tail=100 bilim
docker compose down
```

Dockerfile, compose.yaml, nginx.conf и порт не изменены. Linux: файлы должны быть доступны nginx для чтения (обычные файлы 644, каталоги 755).

## Vercel

Импортируйте GitHub-репозиторий вручную; Framework Preset: Other; Output Directory: `frontend`; Build Command: пусто. Исходный `vercel.json` сохранён. Добавьте домен в Firebase Authentication → Authorized domains. Автоматического деплоя не выполнялось.

## Анимации и зависимости

Three.js **0.160.1**, GSAP / ScrollTrigger **3.12.5** находятся локально в `frontend/assets/vendor` с исходными заголовками лицензий (Three.js LICENSE сохранён отдельно). Нет новой npm-зависимости, сборщика или CDN-скриптов. Заголовок использует локальный Manrope Variable 5.2.5 (латиница и казахская кириллица), лицензия в `frontend/assets/fonts`. Остальной интерфейс сохраняет исходные шрифты с системным fallback.

Реальный WebGL в hero: анимация из присланного пользователем EduCheck HTML — ноутбук появляется, открывается и выпускает карточки журнала, теста и результатов. Брендинг изменён на Bilim, карточки помечены как образцы. Основная книга удалена. По запросу пользователя удалены preview-панель, этапы обучения и курсы. Остался только главный экран. Paths, about и нижняя авторизация удалены из потока страницы. Исходная форма (без изменения полей, ролей и бизнес-логики) открывается native dialog по кнопкам Кіру/Тіркелу с 720ms perspective-анимацией; закрывается крестиком, Esc или кликом по фону. На tablet/mobile меньше геометрии, DPR и частиц, отключены тени основной сцены. Невидимые сцены не анимируются. При reduced motion отключаются ScrollTrigger и движение объектов. При отказе WebGL остаются SVG-ноутбук и символы; форма не зависит от сцены.

Поддерживаются исходные языки **kk / ru**. Английского перевода в исходном проекте не было; новый полный английский интерфейс не заявляется.

В карусели добавлен пятый слайд с числами 1,000+ / 50+ / 98% / 24/7, предоставленными пользователем; эти значения не вычисляются из Firestore и не являются результатом измерений в рамках этой задачи.
