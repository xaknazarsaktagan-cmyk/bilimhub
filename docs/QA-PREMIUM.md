# Проверки Premium Bilim

Выполнено в Chromium (headless, программный WebGL) и Node.js, 29 октября 2026.

- `npm test`: 9 тестов прошли, 0 ошибок. Добавлены регрессии для смешанного текста с Bilim и рендера без Firebase SDK.
- `node --check`: изменённые JavaScript-модули — без синтаксических ошибок.
- Настоящая страница без тестовых подмен: форма рендерится при исходных `PASTE_...`; показывает ошибку конфигурации; WebGL-ноутбук инициализируется; проверены фазы открытия и появления карточек.
- 375 / 768 / 1024 / 1440 px: нет горизонтального переполнения.
- По запросу пользователя верхнее меню удалено. Переключатель светлой/чёрной темы находится справа в шапке; обе темы и сохранение выбора после перезагрузки проверены.
- Роль teacher из карточки сохраняется в форме регистрации; admin отсутствует в регистрации.
- Смена kk/ru сохраняет введённое имя. Статический landing переводится существующим механизмом локализации.
- ScrollTrigger создаётся, scroll-переходы активны; переключение reduced motion удаляет триггеры.
- При блокировке загрузки Three.js и отдельно при недоступном WebGL-контексте форма остаётся доступной, отображается SVG fallback. Финальная страница проверена в Docker с исходным CSP: WebGL и форма инициализируются.
- Браузер: 0 pageerror, 0 ответов 404/500 для локальных ресурсов. Google Fonts может быть недоступен в ограниченной сети: применяется системный шрифт.
- Отдельные **тесты UI-контракта**, только в тестовом браузере с подменой backend module: student signup → student dashboard; student/teacher/admin login → соответствующий dashboard; teacher pending → сообщение и отсутствие перехода; invalid credentials → сообщение ошибки. В поставляемом приложении подмен нет.
- Docker build существующего Dockerfile прошёл; Nginx с read_only, tmpfs и cap_drop ALL запущен; HTTP 200; `nginx -t` успешен. Сначала обнаружены и исправлены только локальные права файлов после распаковки ZIP.

Backend, правила и кабинеты не менялись; их работоспособность на живом Firebase не заявляется.

Core Web Vitals на реальных устройствах и production-сети не измерялись. Актуальные скриншоты главного экрана: `docs/screenshots/desktop.png`, `dark.png`, `mobile.png`; auth.png относится к прежней версии; preview прогресса явно помечен иллюстрацией.

Последняя hero-правка: локальный Manrope с казахскими глифами загружен; новый подзаголовок проверен на kk/ru; старая книга отсутствует. Анимация адаптирована из пользовательского HTML и запускается при открытии; при reduced motion сразу показана открытая композиция.
